# 01-Cpp Basics

A collection of C++ practice programs and notes, organized by topic, building up core language fundamentals.

## Structure

| Folder | Topic | Description |
|---|---|---|
| `01-Basics` | Basics | Syntax fundamentals — variables, data types, I/O, operators |
| `02-Conditional Statements` | Conditionals | `if`, `else if`, `else`, `switch` statements |
| `03-Loops` | Loops | `for`, `while`, `do-while` loops and loop control (`break`/`continue`) |
| `04-Functions` | Functions | Function declaration, definition, parameters, return types, overloading |

## Purpose

Practice code and reference notes for building a strong foundation in C++, used as prep for DSA practice and further coding work.

## Usage

Each folder contains standalone `.cpp` files (and any related notes) for that topic. Compile each file individually with your C++ compiler of choice and run the resulting executable.

## Notes

- Files are organized progressively — later topics build on concepts from earlier ones.
- Comments within each file explain the specific concept being practiced.
- New topic folders will be added here as coverage expands.
